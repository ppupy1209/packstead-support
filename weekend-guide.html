Free guide · Weekend packing

A weekend list you can use again.

Choose the quantities that fit your trip. Write down what you need, then record what is already packed. Print this page from your browser if you prefer a paper copy.

This free guide is separate from the Packstead app, which is being prepared for App Store release.

Keep a useful list for the next trip.

  1. Set your quantities. In Packstead, create a trip from a starter list or your own kit. Edit the item names, categories, and quantities for this trip.
  2. Record what is packed. Tap an item to edit its partial packed count. Tapping the circle marks the full quantity as packed.
  3. Reuse your kit. Choose List options → Save as kit. Starting a trip from that kit creates an independent list with packing checks cleared.

List creation, editing, and packing checks work offline. Before changing devices or uninstalling the app, use Settings → Export backup and keep the file. Importing a backup asks before replacing all current lists.

잘 만든 목록을 다음 여행에도 보관하세요.

  1. 필요 수량을 정하세요. Packstead에서 기본 목록이나 내 키트로 여행을 만드세요. 이번 여행에 맞게 물건 이름, 분류와 수량을 수정할 수 있습니다.
  2. 챙긴 수량을 기록하세요. 물건을 누르면 일부만 챙긴 수량을 수정할 수 있습니다. 원을 누르면 해당 물건의 전체 수량을 챙김으로 표시합니다.
  3. 키트를 다시 쓰세요. 목록 메뉴 → 키트로 저장을 선택하세요. 키트에서 새 여행을 시작하면 챙김 체크가 비워진 독립된 목록이 만들어집니다.

목록 생성·수정·체크는 인터넷 없이 작동합니다. 기기를 바꾸거나 앱을 삭제하기 전에 설정 → 백업 내보내기로 파일을 보관하세요. 백업 가져오기는 확인 후 현재 전체 목록을 교체합니다.
