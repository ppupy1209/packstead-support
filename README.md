# Packstead support

Static bilingual support and privacy pages for the native offline iPhone app. No framework, analytics, cookies, external fonts, or developer backend. Screenshots are actual simulator captures with example trip data.

Publish this repository publicly with GitHub Pages using the included Actions workflow. Source for the app belongs in a separate private repository. Never place signing files, credentials, personal trip backups or private research here.

The production support and privacy pages are live at https://ppupy1209.github.io/packstead-support/ and https://ppupy1209.github.io/packstead-support/privacy.html. Both returned HTTP 200 and matched the repository HTML on September 6, 2026. This confirms website publication; it does not confirm App Store availability.

`weekend-guide.html` is a free English/Korean weekend packing guide with quantities to write in and a print layout. It links to the product preview and existing usage help. The public copy describes release preparation without claiming a live App Store listing or a current review decision. Update purchase links only after current storefront availability is verified. The guide adds no account, form, tracking, script, price, or download badge.

The September 8, 2026 guide update was independently reviewed and checked in the browser at 320, 390, and 1280 CSS pixels. Mobile table headers, English/Korean anchors, the product-page transition, and actual app image loading were checked; the three HTML pages have no broken local links. Print styles are included; a printed PDF has not been inspected. `work/` preview harnesses are ignored. Worktree edits are not published until reviewed changes reach `main` and the existing GitHub Pages workflow succeeds.
